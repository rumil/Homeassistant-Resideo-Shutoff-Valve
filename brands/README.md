# Branding assets

Home Assistant does **not** load an integration's logo from this repository. The
icon shown on the **Settings → Devices & Services** page is served from the
central [`home-assistant/brands`](https://github.com/home-assistant/brands) repo.

Until the assets below are merged there, the HACS workflow keeps `ignore: brands`
in [`.github/workflows/validate.yml`](../.github/workflows/validate.yml).

## Files

`custom_integrations/resideo_shutoff_valve/`

| File | Size | Purpose |
| --- | --- | --- |
| `icon.png` | 256×256 | Required integration icon |
| `icon@2x.png` | 512×512 | Hi-DPI variant |

Both are transparent-background PNGs (a water shut-off valve handwheel on a
water-blue tile). They are generated by [`make_icon.py`](make_icon.py):

```bash
python -m pip install Pillow
python make_icon.py custom_integrations/resideo_shutoff_valve
```

## Submitting to home-assistant/brands

1. Fork <https://github.com/home-assistant/brands>.
2. Copy this folder's `custom_integrations/resideo_shutoff_valve/` into the fork
   at the same path.
3. Open a PR. Once merged, remove the `ignore: brands` line from the validate
   workflow so the HACS check enforces branding.
